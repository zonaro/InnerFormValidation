10 / browser APIs

Integrações que fazem o formulário viver

Autocomplete por CEP

O CEP é o primeiro campo. A busca ViaCEP preenche endereço, complemento, bairro, cidade, UF, IBGE, GIA, DDD, SIAFI e endereço completo.

InnerFormValidation.searchViaCEP(cep, numero, 0, callback)

Geolocalização

Use HTTPS e permissão do navegador. getLocation retorna coordenadas, precisão, altitude, horário e links de mapa; watchLocation acompanha mudanças.

Aguardando ação. 
InnerFormValidation.getLocation(options)
InnerFormValidation.watchLocation(onSuccess, onError, options)
InnerFormValidation.clearLocationWatch(watchId)

11 / extensibilidade

Callbacks e visual customizável

Callbacks declarativos

Os atributos data-beforevalidatecallback, data-validcallback, data-invalidcallback, data-aftervalidatecallback e data-invalidmessage conectam sua UI ao ciclo de validação.

CSS por variáveis

O tema da documentação usa variáveis simples. Altere a cor de destaque para visualizar a ideia.

}
